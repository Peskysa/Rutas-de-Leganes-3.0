# Seguridad

No publiques contraseñas, claves ni datos de clientes en incidencias o ejemplos. Para un fallo con información sensible utiliza la opción de aviso privado de seguridad de GitHub si está habilitada; si no, contacta primero con el propietario sin adjuntar los datos.

Las aplicaciones se ejecutan localmente. Los servidores de ejemplo escuchan en 127.0.0.1 y no deben exponerse a Internet sin autenticación, HTTPS y un despliegue revisado. No se promete ausencia de vulnerabilidades.
