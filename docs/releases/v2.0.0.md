# Rutas de Leganés 3 2.0.0

Modernización del proyecto histórico: interfaz y documentación en español, identidad visual propia, licencia de las aportaciones originales y conservación de las autorías anteriores.

Consulta [el manual](https://github.com/Peskysa/Rutas-de-Leganes-3.0/blob/master/docs/MANUAL.md) y [el historial](https://github.com/Peskysa/Rutas-de-Leganes-3.0/blob/master/CHANGELOG.md) para el alcance funcional.

Incluye Windows, Linux, portable, web y Android. Los paquetes gráficos ejecutan la interfaz local; los formatos propios del backend Python, cuando existe, requieren Python y están documentados. Android compilado y firma comprobada, sin prueba en teléfono físico ni Google Play. Windows sin firma comercial. Fuentes del mismo commit, licencias y sumas SHA-256 adjuntas. Las comprobaciones de Actions deben completarse antes de publicar esta Release.
