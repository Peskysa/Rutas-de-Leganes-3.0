# Rutas-de-Leganes-3.0 2.0.1

Corrige la exportación de coordenadas negativas: los valores numéricos se conservan y el CSV puede importarse de nuevo. Los nombres que comienzan con caracteres de fórmula siguen protegidos para hojas de cálculo.

Prueba de exportación y reimportación incluida. Se mantienen la firma Android del proyecto, las cinco modalidades y sus límites funcionales documentados. Android sin prueba en teléfono físico; Windows sin firma comercial.
